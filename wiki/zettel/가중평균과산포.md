## 가중평균

데이터에 서로 다른 가중치가 부여될 때 사용한다.
공식은 X̄ = Σ(wX) / Σw 이며, w는 각 가중치다 (고급도시교통통계_Week3.pdf p.21).

가중평균을 사용할 수 있는 경우는 다음과 같다 (고급도시교통통계_Week3.pdf p.21).

- 학점을 계산할 때
- 특정 관측값이 집단을 대표할 때

예를 들어 Group Project 10%, Learning Enhancer 30%, 중간고사 60%로 구성된 수업에서, 세 영역 점수가 모두 다른 학생 세 명은 단순평균은 똑같이 60점이지만 가중평균은 각각 43점, 63점, 74점으로 달라진다 (고급도시교통통계_Week3.pdf p.22).
이는 단순평균이 가중치 구조를 반영하지 못한다는 것을 보여준다 (고급도시교통통계_Week3.pdf p.22).

## 중심경향치만으로는 부족한 이유

평균, 중앙값, 최빈값과 같은 중심경향치는 어떤 일이 평균적으로 일어나는지 알려주지만, 모든 값이 그 중심경향치와 같다는 것을 의미하지 않는다 (고급도시교통통계_Week3.pdf p.24).
또한 값들이 중심경향치를 중심으로 어떻게 분포하는지도 알려주지 않는다 (고급도시교통통계_Week3.pdf p.24).

분포를 설명하려면 두 가지 핵심 정보가 필요하다 (고급도시교통통계_Week3.pdf p.25).

- 중심경향치: 하나의 대표값으로 분포를 요약
- 변산성/산포: 데이터가 중심경향치를 중심으로 얼마나 퍼져 있는지를 나타냄

예를 들어 4, 5, 6 / 3, 5, 7 / 2, 5, 8 세 집합은 모두 평균이 5이지만, 4,5,6은 평균 주위에 밀집되어 있고 2,5,8은 평균 주위에 더 흩어져 있다 (고급도시교통통계_Week3.pdf p.26).
즉 중심경향치는 값들이 어느 지점을 중심으로 모이는지는 알려주지만, 그 값이 얼마나 산포되어 있는지는 알려주지 않는다 (고급도시교통통계_Week3.pdf p.26).

## 변동성(산포)의 측정

변동성/산포란 변수 값들이 얼마나 흩어져 있는지, 퍼져있는지, 분산되어있는지를 설명한다 (고급도시교통통계_Week3.pdf p.29).
산포를 나타내는 대표적인 세 가지 지표는 범위(range), 분산(variance), 표준편차(standard deviation)이며, 이 세 지표는 모두 구간척도 또는 비율척도일 때 사용 가능하다 (고급도시교통통계_Week3.pdf p.29).

### 범위

범위 = 최댓값 − 최솟값(또는 가장 큰 값 − 가장 작은 값)이며, 범위가 클수록 데이터의 산포가 커진다 (고급도시교통통계_Week3.pdf p.30).
장점은 데이터 산포의 가장 기본적인 아이디어를 제공한다는 것이다 (고급도시교통통계_Week3.pdf p.30).
단점은 최솟값과 최댓값 두 값만 사용하므로 많은 데이터의 정보를 반영하지 못하고 극단치에 민감하다는 것이다 (고급도시교통통계_Week3.pdf p.30).

예시로 1, 1, 2, 2, 2, 2, 2, 3, 3, 100과 같은 데이터는 극단치 100 때문에 범위가 크게 왜곡될 수 있다 (고급도시교통통계_Week3.pdf p.30).

### 분산과 표준편차

#### 모집단의 분산과 표준편차

평균으로부터의 편차는 X − μ로 정의되며, 모든 편차를 합하면 항상 0이 된다 (고급도시교통통계_Week3.pdf p.35, 41, 44).
0이 되는 것을 막기 위해(음수를 없애기 위해) 편차를 제곱해서 사용하며, 이를 제곱의 합(Sum of Squares, SS)이라 한다 (고급도시교통통계_Week3.pdf p.35, 41, 44).

모집단의 제곱의 합의 평균을 모집단 분산이라 하며, 다음과 같이 계산한다 (고급도시교통통계_Week3.pdf p.35, 44).

σ² = Σ(X − μ)² / N = SS / N

표준편차는 분산의 제곱근이다 (고급도시교통통계_Week3.pdf p.52).

σ = √(Σ(X − μ)² / N) = √(SS / N)

분산의 단위는 "제곱 단위(squared units)"이고, 표준편차는 다시 원래 단위로 돌아온다 (고급도시교통통계_Week3.pdf p.34, 52).

#### 표본의 분산과 표준편차, 자유도

표본에서는 모평균 대신 표본평균(X̄)을 사용하며, 분모도 n이 아니라 n − 1을 사용한다 (고급도시교통통계_Week3.pdf p.46).

s² = Σ(X − X̄)² / (n − 1) = SS / (n − 1)
s = √(Σ(X − X̄)² / (n − 1)) = √(SS / (n − 1))

표본에서 n − 1을 쓰는 이유는 자유도 때문이다.
자유도(degree of freedom)는 표본에서 자유롭게 변할 수 있는 값의 수이며, 표본 분산의 자유도는 df = n − 1이다 (고급도시교통통계_Week3.pdf p.47).
자유도는 보통 표본크기(n)와 추정해야 하는 모수의 개수(k) 두 가지 요인으로 결정되고, 일반 공식은 df = n − k이다 (고급도시교통통계_Week3.pdf p.47).
표본평균 X̄를 사용해 모집단 평균 μ를 추정할 때 자유도 1이 소실된다 (고급도시교통통계_Week3.pdf p.47).

예시: 표본 9, 10, 11, 12, 15의 평균은 11.4이고, 각 편차의 제곱합(SS)은 21.2이다 (고급도시교통통계_Week3.pdf p.53-55).
따라서 s² = 21.2 / 4 = 5.3, s = √5.3 = 2.3이다 (고급도시교통통계_Week3.pdf p.56-57).

#### 도수분포자료에서의 분산과 표준편차

도수(빈도, f)가 있는 자료에서는 편차의 제곱에 도수를 곱한 뒤 더한다 (고급도시교통통계_Week3.pdf p.59).

s² = Σf(X − X̄)² / (n − 1) = SS / (n − 1)

계산 순서는 다음과 같다 (고급도시교통통계_Week3.pdf p.59).

1. 표본평균(X̄) 구하기
2. 각 값에서 평균 빼기(X − X̄)
3. 편차 제곱하기(X − X̄)²
4. 도수와 곱하기
5. 제곱합(SS)의 합 계산
6. n − 1로 나누기 (표준편차는 여기에 제곱근까지 구함)

예시: 일주일 동안 먹은 사과 개수 자료(X=3, f=8 / X=4, f=2 / X=5, f=4, 합계 n=14)에서 평균은 Σ(fX)/n = 52/14 = 3.7이다 (고급도시교통통계_Week3.pdf p.60-61).
SS = 10.86이며, s² = 10.86/13 = 0.84, s = √0.84 = 0.92이다 (고급도시교통통계_Week3.pdf p.64-66).

## 참고: 통계 계산의 수학적 도구

∑(시그마, 그리스 대문자)는 합계(Summation)를 의미하고, X 옆의 아래첨자 i는 X의 개수를 의미한다 (고급도시교통통계_Week3.pdf p.12).
∑X, (∑X)², ∑X²은 서로 다른 계산이다: ∑X는 그냥 다 더하는 것, (∑X)²은 먼저 다 더한 후 제곱하는 것, ∑X²은 각 값을 먼저 제곱한 후 더하는 것이다 (고급도시교통통계_Week3.pdf p.13).
연산 순서는 '괄호(P)-지수(E)-곱/나눗셈(MD)-덧/뺄셈(AS)' 순서를 따른다 (고급도시교통통계_Week3.pdf p.13).

연립방정식을 푸는 두 가지 대표적 방법은 대입법(substitution)과 소거법(elimination)이다 (고급도시교통통계_Week3.pdf p.15).
대입법은 한 식의 미지수를 다른 식에 대입하여 미지수를 줄이는 방법이고, 소거법은 두 방정식을 조합해 한 변수를 제거하고 미지수가 하나인 새 방정식을 만드는 방법이다 (고급도시교통통계_Week3.pdf p.15).

> 이 문서는 my-wiki(2026-2학기 데이터사이언스 수업 실습용 위키)에서 먼저 정리한 것을 이 볼트로 그대로 이식한 것이다. 이 볼트 전체가 왜 `wiki/` + CLAUDE.md 구조로 되어 있는지 설명하는 메타 문서다.

## 문제의식 — 매번 다시 읽는가, 쌓아 두는가

지난 학기 강의노트는 여러 과목이 각자 폴더에 흩어져 있고, 시험 때 한 번 열고 다시 열지 않으며, 과목끼리 어떻게 이어지는지는 아무도 이어 주지 않는다 (데이터 사이언스 수업 02-클로드코드와위키.pdf p.20).

파일을 올려 묻는 방식과 위키로 쌓는 방식을 비교하면:

| | 파일을 올려 묻기 | 위키로 쌓기 |
|---|---|---|
| 질문할 때마다 | 처음부터 다시 읽음 | 이미 정리된 것을 읽음 |
| 과목 간 연결 | 물을 때만 잠깐 | 페이지에 남음 |
| 지난 학기 것 | 다시 올려야 함 | 그대로 있음 |
| 남는 것 | 대화 기록 | 내 폴더의 마크다운 파일 |

쌓이는 쪽이 학기가 갈수록 유리해진다. "여기서 나는 모으고 묻고 판정한다. 페이지는 클로드가 쓴다" (02-클로드코드와위키.pdf p.21).

이 원형은 안드레이 카파시(Andrej Karpathy)의 「LLM Wiki」 글(gist.github.com/karpathy/442a6bf555914893e9891c11519de94f, 2026)에서 가져온 것이다.

## 이 볼트에서의 구조

카파시의 원형(raw/wiki/CLAUDE.md 3계층)을 이 볼트의 기존 구조에 맞춰 다음과 같이 적용했다:

```
Urban Engineering/
  RAW/                     읽기 전용 원자료 — 이미 정리된 내 강의 필기
    GIS (이론)/
    도시경제학/
    도시기반시설/            (팀프로젝트 포함)
    독일과독일사람/
    부동산학개론/
    토지이용계획/
    PRIDE 공유대학/
    환경영향평가 이론 및 실습/
    데이터 사이언스/
    친환경도시계획/
  ,/                       붙여넣은 이미지 — 손대지 않음
  .obsidian/                Obsidian 설정 — 손대지 않음
  wiki/                     클로드가 쓰는 것
    0-Inbox/                아직 분류하지 않은 메모
    1-Projects/             마감 있는 진행 중 과제 MOC
    2-Areas/                이번 학기 과목 MOC
    3-Resources/            주제별 참고 MOC
    4-Archives/             끝난 과목·과제 MOC
    zettel/                 과목을 넘나드는 원자 개념 노트 (옛 topics/)
    index.md                전체 목록
    log.md                  언제 무엇을 넣었나
  CLAUDE.md                 규칙
```

처음에는 원자료 폴더를 볼트 루트에 그대로 두고 읽기 전용으로만 지정했으나, 2026-09-27에 my-wiki의 `raw/`처럼 과목 폴더를 모두 `RAW/` 아래로 모았다. 옮긴 뒤에도 위키의 내부 링크는 끊기지 않았고, 첨부 이미지 폴더 `,/`는 볼트 루트에 그대로 있다 (wiki/log.md 2026-09-27).

## 폴더를 나누는 이유 — 근거의 층위

이 볼트의 과목 폴더는 모두 내가 직접 정리한 필기이므로 근거로서의 무게는 동등하게 취급한다. 다만 어느 과목에서 나온 말인지는 항상 출처로 남긴다 — 예: (RAW/부동산학개론/중간고사/5강 - 부동산경제학 (부동산 시장).md).

## 페이지 두 종류와 규칙 셋

들어온 자료를 먼저 과목별로 읽고, 거기서 개념을 끌어내 `wiki/zettel/`에 남긴다. 순서가 반대면 근거 없는 개념 페이지가 먼저 생긴다.

frontmatter 네 줄: `type`, `title`, `sources`, `status`.

규칙 셋:
1. 출처를 문장 옆에 적는다 — 예: (RAW/도시경제학/기말고사/6강 - 생산요소시장과 소득분배이론.md)
2. 배운 것과 찾은 것을 절로 분리한다 — 뒤 절에 「확인 필요」
3. 다른 페이지로 잇는다 — 이을 곳 없으면 만들지 않는다

규칙 ①이 하는 일: 필기에 없는 문장에는 출처가 없으므로, 규칙만 지키면 지어낸 문장이 저절로 드러난다.

## 과목을 넘나드는 것이 이 위키의 값어치

이 볼트에는 도시경제학·부동산학개론·토지이용계획처럼 서로 겹치는 개념(지대이론, 토지가치, 용도지역제 등)을 다루는 과목이 여럿 있다. 같은 개념이 여러 과목에서 각각 흩어져 있던 것을 `wiki/zettel/` 한 페이지로 모아 각 과목의 출처를 나란히 적는 것이, 파일을 그때그때 올려 묻는 방식으로는 얻을 수 없는 이 위키만의 값어치다.

## 확인 필요

- 이 문서 자체는 my-wiki에서 이식된 것이라 "데이터 사이언스" 폴더가 아직 비어 있던 시점(2026-09-15)의 강의노트 2개(01-왜AI와함께하는가.pdf, 02-클로드코드와위키.pdf)를 근거로 쓰였다. 이 볼트의 데이터 사이언스/ 폴더에 실제로 자료가 채워지면 이 문서의 출처 표기를 다시 확인해야 한다.

## 표준점수(z-score)

### 정의와 공식

표준점수는 값을 표준화하는 방법으로, 모든 데이터를 동일한 척도에 놓고 어떤 값이 평균에서 몇 개의 표준편차만큼 떨어져 있는지를 알려준다 (고급도시교통통계_Week4_수정본.pdf p.20).
표준점수는 방향(direction)과 크기(magnitude)를 함께 가진다 (고급도시교통통계_Week4_수정본.pdf p.20).

모집단에서의 표준점수 공식은 다음과 같다 (고급도시교통통계_Week4_수정본.pdf p.21).

z = (x − μ) / σ

- x = 개별 데이터 값/관측값
- μ = 모집단 평균
- σ = 모집단 표준편차

표준점수는 소수점 둘째 자리까지 표현하며, 값은 거의 항상 −3과 +3 사이에 위치한다 (고급도시교통통계_Week4_수정본.pdf p.21).

예시: 청주시 거주 성인의 평균 연소득이 3천만원, 표준편차가 1천1백만원일 때, 연소득 2천3백만원인 사람의 표준점수는 (23,000−30,000)/11,000 = −0.64이고, 5천5백만원인 사람은 (55,000−30,000)/11,000 = 2.27이다 (고급도시교통통계_Week4_수정본.pdf p.23-24).

### 모집단과 표본에서의 표준점수

모집단 평균이나 표준편차를 모를 때는 표본평균과 표본표준편차로 같은 방식을 사용한다 (고급도시교통통계_Week4_수정본.pdf p.22).

z = (x − X̄) / s

- x = 개별 데이터 값/관측값
- X̄ = 표본 평균
- s = 표본 표준편차

표준점수를 쓰는 이유는 서로 다른 평균·표준편차를 가진 분포의 값을 비교 가능하게 만들기 때문이다.
예를 들어 평균 60점, 표준편차 10점인 중간고사에서 A학생(35점)의 표준점수는 (35−60)/10 = −2.50, B학생(65점)은 +0.50, C학생(90점)은 +3.00이다 (고급도시교통통계_Week4_수정본.pdf p.25-26, 29).
채용 비교 예시에서도 학점만으로는 비교할 수 없는 두 지원자를, 각자 출신 학교의 평균·표준편차로 표준화하면(z=0.25 대 z=0.24) 비교할 수 있다 (고급도시교통통계_Week4_수정본.pdf p.41-42).

## 경험적 법칙(68-95-99.7)과 이상치

경험적 법칙(68-95-99.7 규칙)에 따르면, 전체 값의 약 68%는 −1 ≤ z ≤ 1 사이에, 약 95%는 −2 ≤ z ≤ 2 사이에, 약 99.7%는 −3 ≤ z ≤ 3 사이에 존재한다 (고급도시교통통계_Week4_수정본.pdf p.40).

이상치(outlier)는 |z| > 3인 경우로 정의한다 (고급도시교통통계_Week4_수정본.pdf p.32).
−2와 −3 사이, 2와 3 사이의 값은 특이값(unusual value)으로 분류되고, −1과 1 사이는 일반값(ordinary value)으로 분류된다 (고급도시교통통계_Week4_수정본.pdf p.30, 32).

## 표준점수 역산 (z로부터 X 또는 μ 구하기)

z-score 공식 z = (x − μ)/σ을 거꾸로 풀면 X나 μ를 구할 수 있다.

예시 1: Z = −0.9, μ = 500, σ = 175일 때, −0.9 = (x−500)/175 → −0.9×175 = x−500 → x = 342.5이다 (고급도시교통통계_Week4_수정본.pdf p.44-45).

예시 2: 어떤 아이 키의 표준점수가 2.7이고, 키가 100cm, 표준편차가 5cm일 때, 2.7 = (100−μ)/5 → μ = 100−13.5 = 86.5cm이다 (고급도시교통통계_Week4_수정본.pdf p.46-47).

# Urban Engineering 지식 위키

도시공학 강의 필기를 근거로 쌓아 가는 개인 지식 위키입니다.
[Obsidian](https://obsidian.md) 볼트로 관리하고, [Claude Code](https://claude.com/claude-code)와 함께 정리·연결합니다.

> 이 저장소에는 정리된 `wiki/`만 공개합니다. 원자료(`RAW/`, 강의 필기와 첨부 이미지)는 올리지 않으므로
> 위키 페이지의 출처 링크(`[[RAW/...]]`)는 GitHub에서 열리지 않습니다.

## 시작점

- [`wiki/index.md`](wiki/index.md) — 전체 색인
- [`wiki/log.md`](wiki/log.md) — 작업 기록 (인제스트·구조 최신화 이력)

## 구조

**PARA**(무엇을 위해 보나)와 **제텔카스텐**(개념끼리 어떻게 잇나)을 함께 씁니다.

```
wiki/
├── 0-Inbox/      미분류 메모 임시 보관
├── 1-Projects/   마감이 있는 진행 중 과제
├── 2-Areas/      이번 학기 과목 MOC
├── 3-Resources/  주제별 참고 자료
├── 4-Archives/   끝난 과목·과제
├── zettel/       과목을 넘나드는 원자 개념 노트
└── exports/      Word(.docx)로 내보낸 노트
```

과목 간 연결이 이 위키의 핵심입니다. 같은 개념이 여러 과목에 나오면(예: 지대이론 — 도시경제학·부동산학개론)
`zettel/` 페이지 하나로 모으고 각 과목의 출처를 함께 적습니다.

## 다루는 과목

| 구분 | 과목 |
|---|---|
| 이번 학기 (2-Areas) | 친환경도시계획 · 데이터 사이언스 · 환경영향평가 이론 및 실습 · 고급도시·교통통계 |
| 지난 학기 (4-Archives) | GIS (이론) · 도시경제학 · 도시기반시설 · 독일과독일사람 · 부동산학개론 · 토지이용계획 · PRIDE 공유대학 |

## 작성 규칙

- 원자료는 읽기 전용 근거로 두고, 정리·요약·연결한 결과는 모두 `wiki/`에 둡니다.
- 출처는 내용을 쓴 절(H3·H4) 끝에 따로 단락으로 적습니다.
- 필기에 없는 내용은 절을 갈라 「확인 필요」를 답니다.
- 노트를 추가하면 `index.md`와 `log.md`를 함께 갱신합니다.

## 사용 도구

- **Obsidian** — 노트 작성과 링크 그래프
- **Claude Code** — 노트 정리, 통계청 SGIS 인구 통계 수집
